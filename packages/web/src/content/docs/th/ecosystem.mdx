ชุดโครงการชุมชนที่สร้างขึ้นบน PapeCode

:::note
ต้องการเพิ่มโครงการที่เกี่ยวข้องกับ PapeCode ของคุณลงในรายการนี้หรือไม่ ส่งพีอาร์.
:::

คุณยังสามารถลองดู [awesome-papecode](https://github.com/awesome-papecode/awesome-papecode) และ [papecode.cafe](https://papecode.cafe) ซึ่งเป็นชุมชนที่รวบรวมระบบนิเวศและชุมชนไว้ด้วยกัน
