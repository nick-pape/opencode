CLI PapeCode domyślnie uruchamia [TUI](/docs/tui), gdy wywołasz je bez argumentów.

```bash
papecode
```

CLI obsługuje też polecenia opisane na tej stronie, więc możesz używać PapeCode programowo.

```bash
papecode run "Explain how closures work in JavaScript"
```

---

### tui

Uruchamia interfejs terminalowy (TUI) PapeCode.

```bash
papecode [project]
```

#### Flagi

| Flaga        | Skrót | Opis                                                                    |
| ------------ | ----- | ----------------------------------------------------------------------- |
| `--continue` | `-c`  | Kontynuuj ostatnią sesję                                                |
| `--session`  | `-s`  | Identyfikator sesji do kontynuowania                                    |
| `--fork`     |       | Sklonuj sesję podczas kontynuacji (użyj z `--continue` lub `--session`) |
| `--prompt`   |       | Monit do użycia                                                         |
| `--model`    | `-m`  | Model do użycia w formacie dostawca/model                               |
| `--agent`    |       | Agent do użycia                                                         |
| `--port`     |       | Port do nasłuchiwania                                                   |
| `--hostname` |       | Nazwa hosta, do której należy się powiązać                              |

## Polecenia

Interfejs CLI PapeCode zawiera także dodatkowe polecenia.

---

### agent

Zarządzaj agentami PapeCode.

```bash
papecode agent [command]
```

---

### attach

Dołącz terminal do już działającego serwera backendu PapeCode uruchomionego za pomocą `serve` lub `web`.

```bash
papecode attach [url]
```

Pozwala to połączyć TUI ze zdalnym backendem PapeCode. Na przykład:

```bash
# Start the backend server for web/mobile access
papecode web --port 4096 --hostname 0.0.0.0

# In another terminal, attach the TUI to the running backend
papecode attach http://10.20.30.40:4096
```

#### Flagi

| Flaga       | Skrót | Opis                                    |
| ----------- | ----- | --------------------------------------- |
| `--dir`     |       | Katalog roboczy, w którym uruchomić TUI |
| `--session` | `-s`  | Identyfikator sesji do kontynuowania    |

---

#### create

Utwórz nowego agenta z niestandardową konfiguracją.

```bash
papecode agent create
```

To polecenie poprowadzi Cię przez proces tworzenia nowego agenta z niestandardowym promptem systemowym i konfiguracją narzędzi.

---

#### list

Wyświetl listę wszystkich agentów.

```bash
papecode agent list
```

---

### auth

Zarządzaj danymi uwierzytelniającymi i logowaniem dla dostawców.

```bash
papecode auth [command]
```

---

#### login

PapeCode integruje się z wieloma dostawcami. Możesz użyć `papecode auth login`, aby skonfigurować klucz API dla dowolnego obsługiwanego dostawcy. Klucze są bezpiecznie przechowywane w `~/.local/share/papecode/auth.json`.

```bash
papecode auth login
```

Podczas uruchamiania PapeCode ładuje dostawców z pliku poświadczeń, a także ze zmiennych środowiskowych lub pliku `.env` w Twoim projekcie.

---

#### list

Wyświetl listę wszystkich uwierzytelnionych dostawców przechowywanych w pliku poświadczeń.

```bash
papecode auth list
```

Lub skrócona wersja:

```bash
papecode auth ls
```

---

#### logout

Wyloguj się z dostawcy, usuwając go z pliku poświadczeń.

```bash
papecode auth logout
```

Spowoduje to utworzenie pliku workflow GitHub Actions i poprowadzi Cię przez proces konfiguracji. [Dowiedz się więcej](/docs/github).

##### Flagi

### mcp

Zarządzaj serwerami Model Context Protocol (MCP).

```bash
papecode mcp [command]
```

---

#### add

Dodaj serwer MCP do swojej konfiguracji.

```bash
papecode mcp add
```

To polecenie poprowadzi Cię przez proces dodawania lokalnego lub zdalnego serwera MCP.

---

#### list

Wyświetl listę wszystkich skonfigurowanych serwerów MCP i ich status.

```bash
papecode mcp list
```

Lub skrócona wersja:

```bash
papecode mcp ls
```

---

#### auth

Uwierzytelnij się w serwerze MCP z włączoną funkcją OAuth.

```bash
papecode mcp auth [name]
```

Jeśli nie podasz nazwy serwera, zostaniesz poproszony o wybranie jednego z serwerów wymagających uwierzytelnienia.

Możesz także wyświetlić listę serwerów obsługujących OAuth i ich status uwierzytelnienia.

```bash
papecode mcp auth list
```

Lub skrócona wersja:

```bash
papecode mcp auth ls
```

---

#### logout

Usuń tokeny OAuth dla serwera MCP.

```bash
papecode mcp logout [name]
```

---

#### debug

Debuguj problemy z połączeniem OAuth dla serwera MCP.

```bash
papecode mcp debug <name>
```

---

### models

Wyświetl listę modeli ze wszystkich skonfigurowanych dostawców.

```bash
papecode models [provider]
```

Pokazuje modele dostępne do użycia w `provider/model`.

Jest to identyfikator modelu, którego używasz w [konfiguracji](/docs/config).

Opcjonalnie możesz podać identyfikator dostawcy, aby filtrować modele według tego dostawcy.

```bash
papecode models anthropic
```

#### Flagi

| Flaga       | Opis                                                                            |
| ----------- | ------------------------------------------------------------------------------- |
| `--refresh` | Odśwież pamięć podręczną modeli                                                 |
| `--verbose` | Bardziej szczegółowe dane wyjściowe modelu (zawiera metadane, takie jak koszty) |

Użyj flagi `--refresh`, aby zaktualizować listę modeli w pamięci podręcznej. Jest to przydatne, gdy dostawca dodał nowe modele, które chcesz zobaczyć w PapeCode.

```bash
papecode models --refresh
```

### run

Uruchom PapeCode w trybie nieinteraktywnym, przekazując bezpośrednio prompt.

```bash
papecode run [message..]
```

Jest to przydatne do tworzenia skryptów, automatyzacji lub gdy chcesz wysłać szybkie zapytanie bez uruchamiania TUI. Na przykład:

```bash "papecode run"
papecode run Explain the use of context in Go
```

Można również użyć tego z działającym `papecode serve`, aby uniknąć zimnego startu serwera MCP przy każdym uruchomieniu:

```bash
# Start a headless server in one terminal
papecode serve

# In another terminal, run commands that attach to it
papecode run --attach http://localhost:4096 "Explain async/await in JavaScript"
```

#### Flagi

| Flaga        | Skrót | Opis                                                                    |
| ------------ | ----- | ----------------------------------------------------------------------- |
| `--command`  |       | Polecenie do uruchomienia, reszta to argumenty                          |
| `--continue` | `-c`  | Kontynuuj ostatnią sesję                                                |
| `--session`  | `-s`  | Identyfikator sesji do kontynuowania                                    |
| `--fork`     |       | Sklonuj sesję podczas kontynuacji (użyj z `--continue` lub `--session`) |
| `--share`    |       | Udostępnij sesję po zakończeniu                                         |
| `--model`    | `-m`  | Model do użycia w formacie dostawca/model                               |
| `--agent`    |       | Agent do użycia                                                         |
| `--file`     | `-f`  | Pliki do załączenia do wiadomości                                       |
| `--format`   |       | Format wyjściowy: `default` (sformatowany) lub `json` (surowy JSON)     |
| `--title`    |       | Tytuł sesji (jeśli nie podano, zostanie wygenerowany z promptu)         |
| `--attach`   |       | Dołącz do działającego serwera PapeCode (np. http://localhost:4096)     |
| `--port`     |       | Port dla serwera lokalnego (domyślnie losowy)                           |

### serve

Uruchom serwer PapeCode (bez interfejsu) w celu uzyskania dostępu do API. Pełny opis API HTTP znajduje się w [dokumentacji serwera](/docs/server).

```bash
papecode serve
```

Uruchamia to serwer HTTP, który zapewnia dostęp do API PapeCode bez interfejsu TUI. Ustaw `PAPECODE_SERVER_PASSWORD`, aby włączyć podstawowe uwierzytelnianie HTTP (domyślna nazwa użytkownika to `papecode`).

#### Flagi

| Flaga        | Opis                                       |
| ------------ | ------------------------------------------ |
| `--port`     | Port do nasłuchiwania                      |
| `--hostname` | Nazwa hosta, do której należy się powiązać |
| `--mdns`     | Włącz wykrywanie mDNS                      |
| `--cors`     | Dodatkowe dozwolone źródła CORS            |

### stats

Pokaż statystyki wykorzystania tokenów i sesji PapeCode.

```bash
papecode stats
```

#### Flagi

| Flaga       | Opis                                                                                  |
| ----------- | ------------------------------------------------------------------------------------- |
| `--days`    | Pokaż statystyki z ostatnich N dni (domyślnie: cały czas)                             |
| `--tools`   | Pokaż użycie poszczególnych narzędzi (domyślnie: wszystkie)                           |
| `--models`  | Pokaż podział na modele (domyślnie ukryty). Podaj liczbę, aby pokazać N najczęstszych |
| `--project` | Filtruj według projektu (domyślnie: wszystkie projekty, pusty ciąg: bieżący projekt)  |

### export

Eksportuj dane sesji jako JSON.

```bash
papecode export [sessionID]
```

Jeśli nie podasz identyfikatora sesji, zostaniesz poproszony o wybranie jednej z ostatnich sesji.

---

### import

Importuj dane sesji z pliku JSON lub adresu URL udostępniania PapeCode.

```bash
papecode import <file>
```

Możesz importować z pliku lokalnego lub adresu URL.

```bash
papecode import session.json
papecode import https://opncd.ai/s/abc123
```

---

### web

Uruchom serwer PapeCode z interfejsem internetowym.

```bash
papecode web
```

Uruchamia to serwer HTTP i udostępnia PapeCode przez interfejs przeglądarkowy. Ustaw `PAPECODE_SERVER_PASSWORD`, aby włączyć podstawowe uwierzytelnianie HTTP (domyślna nazwa użytkownika to `papecode`).

#### Flagi

| Flaga        | Opis                                       |
| ------------ | ------------------------------------------ |
| `--port`     | Port do nasłuchiwania                      |
| `--hostname` | Nazwa hosta, do której należy się powiązać |
| `--mdns`     | Włącz wykrywanie mDNS                      |
| `--cors`     | Dodatkowe dozwolone źródła CORS            |

### acp

Uruchom serwer ACP (Agent Client Protocol).

```bash
papecode acp
```

Uruchamia serwer ACP, który komunikuje się przez stdin/stdout przy użyciu JSON-RPC.

#### Flagi

| Flaga        | Opis                                       |
| ------------ | ------------------------------------------ |
| `--cwd`      | Katalog roboczy                            |
| `--port`     | Port do nasłuchiwania                      |
| `--hostname` | Nazwa hosta, do której należy się powiązać |

---

### uninstall

Odinstaluj PapeCode i usuń wszystkie powiązane pliki.

```bash
papecode uninstall
```

#### Flagi

| Flaga           | Skrót | Opis                          |
| --------------- | ----- | ----------------------------- |
| `--keep-config` | `-c`  | Zachowaj pliki konfiguracyjne |
| `--keep-data`   | `-d`  | Zachowaj dane sesji i migawki |
| `--dry-run`     |       | Pokaż co zostanie usunięte    |
| `--force`       | `-f`  | Pomiń monity o potwierdzenie  |

---

### upgrade

Aktualizuj PapeCode do najnowszej lub określonej wersji.

```bash
papecode upgrade [target]
```

Aby zaktualizować do najnowszej wersji:

```bash
papecode upgrade
```

Aby zaktualizować do konkretnej wersji:

```bash
papecode upgrade v0.1.48
```

#### Flagi

| Flaga      | Skrót | Opis                                                |
| ---------- | ----- | --------------------------------------------------- |
| `--method` | `-m`  | Wymuś metodę instalacji: curl, npm, pnpm, bun, brew |

## Zmienne środowiskowe

PapeCode można skonfigurować za pomocą zmiennych środowiskowych.

| Zmienna                               | Typ     | Opis                                                       |
| ------------------------------------- | ------- | ---------------------------------------------------------- |
| `PAPECODE_AUTO_SHARE`                 | boolean | Automatycznie udostępniaj sesje                            |
| `PAPECODE_GIT_BASH_PATH`              | string  | Ścieżka do pliku wykonywalnego Git Bash w systemie Windows |
| `PAPECODE_CONFIG`                     | string  | Ścieżka do pliku konfiguracyjnego                          |
| `PAPECODE_TUI_CONFIG`                 | string  | Ścieżka do pliku konfiguracyjnego TUI                      |
| `PAPECODE_CONFIG_DIR`                 | string  | Ścieżka do katalogu konfiguracyjnego                       |
| `PAPECODE_CONFIG_CONTENT`             | string  | Treść konfiguracji JSON (inline)                           |
| `PAPECODE_DISABLE_AUTOUPDATE`         | boolean | Wyłącz automatyczne sprawdzanie aktualizacji               |
| `PAPECODE_DISABLE_PRUNE`              | boolean | Wyłącz czyszczenie starych wyników (pruning)               |
| `PAPECODE_DISABLE_TERMINAL_TITLE`     | boolean | Wyłącz automatyczne ustawianie tytułu terminala            |
| `PAPECODE_PERMISSION`                 | string  | Konfiguracja uprawnień w JSON (inline)                     |
| `PAPECODE_DISABLE_DEFAULT_PLUGINS`    | boolean | Wyłącz domyślne wtyczki                                    |
| `PAPECODE_DISABLE_LSP_DOWNLOAD`       | boolean | Wyłącz automatyczne pobieranie serwerów LSP                |
| `PAPECODE_ENABLE_EXPERIMENTAL_MODELS` | boolean | Włącz modele eksperymentalne                               |
| `PAPECODE_DISABLE_AUTOCOMPACT`        | boolean | Wyłącz automatyczne kompaktowanie kontekstu                |
| `PAPECODE_DISABLE_CLAUDE_CODE`        | boolean | Wyłącz integrację z `.claude` (prompt + skills)            |
| `PAPECODE_DISABLE_CLAUDE_CODE_PROMPT` | boolean | Wyłącz czytanie `~/.claude/CLAUDE.md`                      |
| `PAPECODE_DISABLE_CLAUDE_CODE_SKILLS` | boolean | Wyłącz ładowanie `.claude/skills`                          |
| `PAPECODE_DISABLE_MODELS_FETCH`       | boolean | Wyłącz pobieranie modeli ze źródeł zewnętrznych            |
| `PAPECODE_FAKE_VCS`                   | string  | Fałszywy dostawca VCS do celów testowych                   |
| `PAPECODE_CLIENT`                     | string  | Identyfikator klienta (domyślnie `cli`)                    |
| `PAPECODE_ENABLE_EXA`                 | boolean | Włącz narzędzie wyszukiwania internetowego Exa             |
| `PAPECODE_SERVER_PASSWORD`            | string  | Włącz uwierzytelnianie podstawowe dla `serve`/`web`        |
| `PAPECODE_SERVER_USERNAME`            | string  | Nazwa użytkownika do autoryzacji (domyślnie `papecode`)    |
| `PAPECODE_MODELS_URL`                 | string  | Niestandardowy adres URL do pobierania konfiguracji modeli |

### Eksperymentalne

Te zmienne włączają funkcje eksperymentalne, które mogą ulec zmianie lub zostać usunięte.

| Zmienna                                         | Typ     | Opis                                         |

| `PAPECODE_EXPERIMENTAL`                         | boolean | Włącz wszystkie funkcje eksperymentalne      |
| `PAPECODE_EXPERIMENTAL_ICON_DISCOVERY`          | boolean | Włącz wykrywanie ikon                        |
| `PAPECODE_EXPERIMENTAL_DISABLE_COPY_ON_SELECT`  | boolean | Wyłącz kopiowanie przy zaznaczaniu w TUI     |
| `PAPECODE_EXPERIMENTAL_BASH_DEFAULT_TIMEOUT_MS` | number  | Domyślny limit czasu dla narzędzia bash w ms |

| `PAPECODE_EXPERIMENTAL_FILEWATCHER`             | boolean | Włącz obserwatora plików dla całego katalogu |
| `PAPECODE_EXPERIMENTAL_OXFMT`                   | boolean | Włącz formater oxfmt                         |
| `PAPECODE_EXPERIMENTAL_LSP_TOOL`                | boolean | Włącz eksperymentalne narzędzie LSP          |
| `PAPECODE_EXPERIMENTAL_DISABLE_FILEWATCHER`     | boolean | Wyłącz obserwatora plików                    |
| `PAPECODE_EXPERIMENTAL_EXA`                     | boolean | Włącz funkcje eksperymentalne Exa            |
| `PAPECODE_EXPERIMENTAL_LSP_TY`                  | boolean | Włącz TY LSP dla plików python               |
| `PAPECODE_EXPERIMENTAL_MARKDOWN`                | boolean | Włącz funkcje eksperymentalne Markdown       |
| `PAPECODE_EXPERIMENTAL_PLAN_MODE`               | boolean | Włącz tryb planowania                        |
