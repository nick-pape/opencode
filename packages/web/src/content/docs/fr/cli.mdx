La CLI PapeCode démarre par défaut le [TUI](/docs/tui) lorsqu'il est exécuté sans aucun argument.

```bash
papecode
```

Mais elle accepte également les commandes documentées sur cette page. Cela vous permet d'interagir avec PapeCode par programme.

```bash
papecode run "Explain how closures work in JavaScript"
```

---

### tui

Démarrez l’interface utilisateur du terminal PapeCode.

```bash
papecode [project]
```

#### Options

| Option       | Court | Description                                                                   |
| ------------ | ----- | ----------------------------------------------------------------------------- |
| `--continue` | `-c`  | Continuer la dernière session                                                 |
| `--session`  | `-s`  | ID de session pour continuer                                                  |
| `--fork`     |       | Forker la session en continuant (à utiliser avec `--continue` ou `--session`) |
| `--prompt`   |       | Prompt à utiliser                                                             |
| `--model`    | `-m`  | Modèle à utiliser sous forme de fournisseur/modèle                            |
| `--agent`    |       | Agent à utiliser                                                              |
| `--port`     |       | Port d'écoute                                                                 |
| `--hostname` |       | Nom d'hôte d'écoute                                                           |

## Commandes

La CLI PapeCode dispose également des commandes suivantes.

---

### agent

Gérer les agents pour PapeCode.

```bash
papecode agent [command]
```

---

### attach

Attachez un terminal à un serveur backend PapeCode déjà en cours d'exécution démarré via les commandes `serve` ou `web`.

```bash
papecode attach [url]
```

Cela permet d'utiliser le TUI avec un backend PapeCode distant. Par exemple :

```bash
# Start the backend server for web/mobile access
papecode web --port 4096 --hostname 0.0.0.0

# In another terminal, attach the TUI to the running backend
papecode attach http://10.20.30.40:4096
```

#### Options

| Option      | Court | Description                                    |
| ----------- | ----- | ---------------------------------------------- |
| `--dir`     |       | Répertoire de travail dans lequel démarrer TUI |
| `--session` | `-s`  | ID de session pour continuer                   |

---

#### create

Créez un nouvel agent avec une configuration personnalisée.

```bash
papecode agent create
```

Cette commande vous guidera dans la création d'un nouvel agent avec un prompt système personnalisé et une configuration d'outils.

---

#### list

Liste tous les agents disponibles.

```bash
papecode agent list
```

---

### auth

Commande pour gérer les informations d’identification et la connexion des fournisseurs.

```bash
papecode auth [command]
```

---

#### login

PapeCode est alimenté par la liste des fournisseurs sur [Models.dev](https://models.dev), vous pouvez donc utiliser `papecode auth login` pour configurer les clés API pour tout fournisseur que vous souhaitez utiliser. Ceci est stocké dans `~/.local/share/papecode/auth.json`.

```bash
papecode auth login
```

Lorsque PapeCode démarre, il charge les fournisseurs à partir du fichier d'informations d'identification, ainsi que les clés définies dans vos environnements ou un fichier `.env` dans votre projet.

---

#### list

Liste tous les fournisseurs authentifiés tels qu'ils sont stockés dans le fichier d'informations d'identification.

```bash
papecode auth list
```

Ou la version courte.

```bash
papecode auth ls
```

---

#### logout

Vous déconnecte d'un fournisseur en l'effaçant du fichier d'informations d'identification.

```bash
papecode auth logout
```

---

### github

Gérez l'agent GitHub pour l'automatisation du dépôt.

```bash
papecode github [command]
```

---

#### install

Installez l'agent GitHub dans votre dépôt.

```bash
papecode github install
```

Cela configure le flux de travail GitHub Actions nécessaire et vous guide tout au long du processus de configuration. [En savoir plus](/docs/github).

---

#### run

Exécutez l'agent GitHub. Ceci est généralement utilisé dans les GitHub Actions.

```bash
papecode github run
```

##### Options

| Option    | Description                                          |
| --------- | ---------------------------------------------------- |
| `--event` | Événement simulé GitHub pour lequel exécuter l'agent |
| `--token` | Jeton d'accès personnel GitHub                       |

### MCP

Gérer les serveurs Model Context Protocol.

```bash
papecode mcp [command]
```

---

#### add

Ajoutez un serveur MCP à votre configuration.

```bash
papecode mcp add
```

Cette commande vous guidera dans l’ajout d’un serveur MCP local ou distant.

---

#### list

Liste tous les serveurs MCP configurés et leur état de connexion.

```bash
papecode mcp list
```

Ou utilisez la version courte.

```bash
papecode mcp ls
```

---

#### auth

Authentifiez-vous auprès d'un serveur MCP compatible OAuth.

```bash
papecode mcp auth [name]
```

Si vous ne fournissez pas de nom de serveur, vous serez invité à sélectionner parmi les serveurs compatibles OAuth disponibles.

Vous pouvez également répertorier les serveurs compatibles OAuth et leur statut d'authentification.

```bash
papecode mcp auth list
```

Ou utilisez la version courte.

```bash
papecode mcp auth ls
```

---

#### logout

Supprimez les informations d'identification OAuth pour un serveur MCP.

```bash
papecode mcp logout [name]
```

---

#### debug

Déboguer les problèmes de connexion OAuth pour un serveur MCP.

```bash
papecode mcp debug <name>
```

---

### models

Liste tous les modèles disponibles auprès des fournisseurs configurés.

```bash
papecode models [provider]
```

Cette commande affiche tous les modèles disponibles parmi vos fournisseurs configurés au format `provider/model`.

Ceci est utile pour déterminer le nom exact du modèle à utiliser dans [votre config](/docs/config/).

Vous pouvez éventuellement transmettre un ID de fournisseur pour filtrer les modèles en fonction de ce fournisseur.

```bash
papecode models anthropic
```

#### Options

| Option      | Description                                                                                |
| ----------- | ------------------------------------------------------------------------------------------ |
| `--refresh` | Actualisez le cache des modèles à partir de models.dev                                     |
| `--verbose` | Utiliser une sortie de modèle plus détaillée (inclut des métadonnées telles que les coûts) |

Utilisez l'option `--refresh` pour mettre à jour la liste des modèles mis en cache. Ceci est utile lorsque de nouveaux modèles ont été ajoutés à un fournisseur et que vous souhaitez les voir dans PapeCode.

```bash
papecode models --refresh
```

---

### run

Exécutez papecode en mode non interactif en transmettant directement un prompt.

```bash
papecode run [message..]
```

Ceci est utile pour les scripts, l'automatisation ou lorsque vous souhaitez une réponse rapide sans lancer le TUI complet. Par exemple :

```bash "papecode run"
papecode run Explain the use of context in Go
```

Vous pouvez également vous connecter à une instance `papecode serve` en cours d'exécution pour éviter les temps de démarrage à froid du serveur MCP à chaque exécution :

```bash
# Start a headless server in one terminal
papecode serve

# In another terminal, run commands that attach to it
papecode run --attach http://localhost:4096 "Explain async/await in JavaScript"
```

#### Options

| Option       | Court | Description                                                                                    |
| ------------ | ----- | ---------------------------------------------------------------------------------------------- |
| `--command`  |       | La commande à exécuter, utilisez le message pour les arguments                                 |
| `--continue` | `-c`  | Continuer la dernière session                                                                  |
| `--session`  | `-s`  | ID de session pour continuer                                                                   |
| `--fork`     |       | Forker la session en continuant (à utiliser avec `--continue` ou `--session`)                  |
| `--share`    |       | Partager la session                                                                            |
| `--model`    | `-m`  | Modèle à utiliser sous forme de fournisseur/modèle                                             |
| `--agent`    |       | Agent à utiliser                                                                               |
| `--file`     | `-f`  | Fichier(s) à joindre au message                                                                |
| `--format`   |       | Format : par défaut (formaté) ou json (événements JSON bruts)                                  |
| `--title`    |       | Titre de la session (utilise un prompt tronqué si aucune valeur n'est fournie)                 |
| `--attach`   |       | Connectez-vous à un serveur papecode en cours d'exécution (par exemple, http://localhost:4096) |
| `--port`     |       | Port du serveur local (port aléatoire par défaut)                                              |

### serve

Démarrez un serveur PapeCode sans interface graphique pour un accès API. Consultez le [serveur docs](/docs/server) pour l'interface complète HTTP.

```bash
papecode serve
```

Cela démarre un serveur HTTP qui fournit un accès API aux fonctionnalités d'PapeCode sans l'interface TUI. Définissez `PAPECODE_SERVER_PASSWORD` pour activer l'authentification de base HTTP (le nom d'utilisateur par défaut est `papecode`).

#### Options

| Option       | Description                                                |
| ------------ | ---------------------------------------------------------- |
| `--port`     | Port d'écoute                                              |
| `--hostname` | Nom d'hôte d'écoute                                        |
| `--mdns`     | Activer la découverte mDNS                                 |
| `--cors`     | Origines de navigateur supplémentaires pour autoriser CORS |

### session

Gérer les sessions PapeCode.

```bash
papecode session [command]
```

---

#### list

Liste toutes les sessions PapeCode.

```bash
papecode session list
```

##### Options

| Option        | Court | Description                                  |
| ------------- | ----- | -------------------------------------------- |
| `--max-count` | `-n`  | Limiter aux N sessions les plus récentes     |
| `--format`    |       | Format de sortie : tableau ou json (tableau) |

---

### stats

Affichez les statistiques d'utilisation et de coût des jetons pour vos sessions PapeCode.

```bash
papecode stats
```

#### Options

| Option      | Description                                                                                                           |
| ----------- | --------------------------------------------------------------------------------------------------------------------- |
| `--days`    | Afficher les statistiques des N derniers jours (depuis le début)                                                      |
| `--tools`   | Nombre d'outils à afficher (tous)                                                                                     |
| `--models`  | Afficher la répartition de l'utilisation du modèle (masqué par défaut). Passez un numéro pour afficher les N premiers |
| `--project` | Filtrer par projet (tous les projets, chaîne vide : projet actuel)                                                    |

---

### export

Exportez les données de session au format JSON.

```bash
papecode export [sessionID]
```

Si vous ne fournissez pas d'ID de session, vous serez invité à sélectionner parmi les sessions disponibles.

---

### import

Importez les données de session à partir d'un fichier JSON ou d'une URL de partage PapeCode.

```bash
papecode import <file>
```

Vous pouvez importer à partir d'un fichier local ou d'une URL de partage PapeCode.

```bash
papecode import session.json
papecode import https://opncd.ai/s/abc123
```

---

### web

Démarrez un serveur PapeCode sans interface graphique avec une interface Web.

```bash
papecode web
```

Cela démarre un serveur HTTP et ouvre un navigateur Web pour accéder à PapeCode via une interface Web. Définissez `PAPECODE_SERVER_PASSWORD` pour activer l'authentification de base HTTP (le nom d'utilisateur par défaut est `papecode`).

#### Options

| Option       | Description                                                |
| ------------ | ---------------------------------------------------------- |
| `--port`     | Port d'écoute                                              |
| `--hostname` | Nom d'hôte d'écoute                                        |
| `--mdns`     | Activer la découverte mDNS                                 |
| `--cors`     | Origines de navigateur supplémentaires pour autoriser CORS |

---

### acp

Démarrez un serveur ACP (Agent Client Protocol).

```bash
papecode acp
```

Cette commande démarre un serveur ACP qui communique via stdin/stdout en utilisant nd-JSON.

#### Options

| Option       | Description           |
| ------------ | --------------------- |
| `--cwd`      | Répertoire de travail |
| `--port`     | Port d'écoute         |
| `--hostname` | Nom d'hôte d'écoute   |

---

### uninstall

Désinstallez PapeCode et supprimez tous les fichiers associés.

```bash
papecode uninstall
```

#### Options

| Option          | Court | Description                                         |
| --------------- | ----- | --------------------------------------------------- |
| `--keep-config` | `-c`  | Conserver les fichiers de configuration             |
| `--keep-data`   | `-d`  | Conserver les données de session et les instantanés |
| `--dry-run`     |       | Afficher ce qui serait supprimé sans supprimer      |
| `--force`       | `-f`  | Ignorer les invites de confirmation                 |

---

### upgrade

Met à jour papecode vers la dernière version ou une version spécifique.

```bash
papecode upgrade [target]
```

Pour mettre à niveau vers la dernière version.

```bash
papecode upgrade
```

Pour passer à une version spécifique.

```bash
papecode upgrade v0.1.48
```

#### Options

| Option     | Court | Description                                                     |
| ---------- | ----- | --------------------------------------------------------------- |
| `--method` | `-m`  | La méthode d'installation utilisée ; curl, npm, pnpm, bun, brew |

## Variables d'environnement

PapeCode peut être configuré à l'aide de variables d'environnement.

| Variables                             | Type    | Description                                                                       |
| ------------------------------------- | ------- | --------------------------------------------------------------------------------- |
| `PAPECODE_AUTO_SHARE`                 | booléen | Partager automatiquement des sessions                                             |
| `PAPECODE_GIT_BASH_PATH`              | chaîne  | Chemin vers l'exécutable Git Bash sur Windows                                     |
| `PAPECODE_CONFIG`                     | chaîne  | Chemin d'accès au fichier de configuration                                        |
| `PAPECODE_TUI_CONFIG`                 | chaîne  | Chemin d'accès au fichier de configuration TUI                                    |
| `PAPECODE_CONFIG_DIR`                 | chaîne  | Chemin d'accès au répertoire de configuration                                     |
| `PAPECODE_CONFIG_CONTENT`             | chaîne  | Contenu de configuration JSON en ligne                                            |
| `PAPECODE_DISABLE_AUTOUPDATE`         | booléen | Désactiver les vérifications automatiques des mises à jour                        |
| `PAPECODE_DISABLE_PRUNE`              | booléen | Désactiver le nettoyage des anciennes données                                     |
| `PAPECODE_DISABLE_TERMINAL_TITLE`     | booléen | Désactiver les mises à jour automatiques des titres du terminal                   |
| `PAPECODE_PERMISSION`                 | chaîne  | Configuration des autorisations JSON intégrées                                    |
| `PAPECODE_DISABLE_DEFAULT_PLUGINS`    | booléen | Désactiver les plugins par défaut                                                 |
| `PAPECODE_DISABLE_LSP_DOWNLOAD`       | booléen | Désactiver les téléchargements automatiques du serveur LSP                        |
| `PAPECODE_ENABLE_EXPERIMENTAL_MODELS` | booléen | Activer les modèles expérimentaux                                                 |
| `PAPECODE_DISABLE_AUTOCOMPACT`        | booléen | Désactiver le compactage automatique du contexte                                  |
| `PAPECODE_DISABLE_CLAUDE_CODE`        | booléen | Désactiver la lecture de `.claude` (prompt + compétences)                         |
| `PAPECODE_DISABLE_CLAUDE_CODE_PROMPT` | booléen | Désactiver la lecture `~/.claude/CLAUDE.md`                                       |
| `PAPECODE_DISABLE_CLAUDE_CODE_SKILLS` | booléen | Désactiver le chargement de `.claude/skills`                                      |
| `PAPECODE_DISABLE_MODELS_FETCH`       | booléen | Désactiver la récupération de modèles à partir de sources distantes               |
| `PAPECODE_FAKE_VCS`                   | chaîne  | Faux fournisseur VCS à des fins de test                                           |
| `PAPECODE_CLIENT`                     | chaîne  | Identifiant du client (par défaut `cli`)                                          |
| `PAPECODE_ENABLE_EXA`                 | booléen | Activer les outils de recherche Web Exa                                           |
| `PAPECODE_SERVER_PASSWORD`            | chaîne  | Activer l'authentification de base pour `serve`/`web`                             |
| `PAPECODE_SERVER_USERNAME`            | chaîne  | Remplacer le nom d'utilisateur d'authentification de base (par défaut `papecode`) |
| `PAPECODE_MODELS_URL`                 | chaîne  | URL personnalisé pour récupérer la configuration des modèles                      |

| `PAPECODE_EXPERIMENTAL_LSP_TOOL`                | booléen | Activer l'outil expérimental LSP                                |
| `PAPECODE_EXPERIMENTAL_DISABLE_FILEWATCHER`     | booléen | Désactiver l'observateur de fichiers                            |
| `PAPECODE_EXPERIMENTAL_EXA`                     | booléen | Activer les fonctionnalités Exa expérimentales                  |
| `PAPECODE_EXPERIMENTAL_LSP_TY`                  | booléen | Activer TY LSP pour les fichiers python                         |
| `PAPECODE_EXPERIMENTAL_MARKDOWN`                | booléen | Activer les fonctionnalités Markdown expérimentales             |
| `PAPECODE_EXPERIMENTAL_PLAN_MODE`               | booléen | Activer le mode plan                                            |
