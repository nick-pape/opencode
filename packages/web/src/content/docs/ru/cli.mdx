CLI papecode по умолчанию запускает [TUI](/docs/tui) при запуске без каких-либо аргументов.

```bash
papecode
```

Но он также принимает команды, описанные на этой странице. Это позволяет вам программно взаимодействовать с papecode.

```bash
papecode run "Explain how closures work in JavaScript"
```

---

### tui

Запустите TUI papecode.

```bash
papecode [project]
```

#### Флаги

| Флаг         | Короткий | Описание                                                                      |
| ------------ | -------- | ----------------------------------------------------------------------------- |
| `--continue` | `-c`     | Продолжить последний сеанс                                                    |
| `--session`  | `-s`     | Идентификатор сеанса для продолжения                                          |
| `--fork`     |          | Разветвить сеанс при продолжении (используйте с `--continue` или `--session`) |
| `--prompt`   |          | Промпт для использования                                                      |
| `--model`    | `-m`     | Модель для использования в виде поставщика/модели.                            |
| `--agent`    |          | Агент для использования                                                       |
| `--port`     |          | Порт для прослушивания                                                        |
| `--hostname` |          | Имя хоста для прослушивания                                                   |

## Команды

CLI papecode также имеет следующие команды.

---

### agent

Управляйте агентами для papecode.

```bash
papecode agent [command]
```

---

### attach

Подключите терминал к уже работающему внутреннему серверу papecode, запущенному с помощью команд `serve` или `web`.

```bash
papecode attach [url]
```

Это позволяет использовать TUI с удаленным сервером papecode. Например:

```bash
# Start the backend server for web/mobile access
papecode web --port 4096 --hostname 0.0.0.0

# In another terminal, attach the TUI to the running backend
papecode attach http://10.20.30.40:4096
```

#### Флаги

| Флаг        | Короткий | Описание                             |
| ----------- | -------- | ------------------------------------ |
| `--dir`     |          | Рабочий каталог для запуска TUI      |
| `--session` | `-s`     | Идентификатор сеанса для продолжения |

Эта команда поможет вам создать новый агент с настраиваемой системной подсказкой и настройкой инструмента.

Перечислите всех доступных агентов.


### auth

Команда для управления учетными данными и входом в систему для провайдеров.

```bash
papecode auth [command]
```

---

#### login

papecode использует список провайдеров с [Models.dev](https://models.dev), поэтому вы можете использовать `papecode auth login` для настройки ключей API для любого поставщика, которого вы хотите использовать. Это хранится в `~/.local/share/papecode/auth.json`.

```bash
papecode auth login
```

Когда papecode запускается, он загружает поставщиков из файла учетных данных. И если в ваших средах определены какие-либо ключи или файл `.env` в вашем проекте.

---

#### list

Перечисляет всех проверенных поставщиков, которые хранятся в файле учетных данных.

```bash
papecode auth list
```

Или короткая версия.

```bash
papecode auth ls
```

---

#### logout

Выключает вас из провайдера, удаляя его из файла учетных данных.

```bash
papecode auth logout
```

#### add

#### list

Или используйте короткую версию.


#### auth

Аутентификация с помощью сервера MCP с поддержкой OAuth.

```bash
papecode mcp auth [name]
```

Если вы не укажете имя сервера, вам будет предложено выбрать один из доступных серверов с поддержкой OAuth.

Вы также можете перечислить серверы с поддержкой OAuth и их статус аутентификации.

```bash
papecode mcp auth list
```

Или используйте короткую версию.

```bash
papecode mcp auth ls
```

---

#### logout

Удалите учетные данные OAuth для сервера MCP.

```bash
papecode mcp logout [name]
```

#### debug

Отладка проблем с подключением OAuth для сервера MCP.

```bash
papecode mcp debug <name>
```

### models

Перечислите все доступные модели от настроенных поставщиков.

```bash
papecode models [provider]
```

Эта команда отображает все модели, доступные у настроенных вами поставщиков, в формате `provider/model`.

Это полезно для определения точного названия модели, которое будет использоваться в [вашем config](/docs/config/).

При желании вы можете передать идентификатор поставщика, чтобы фильтровать модели по этому поставщику.

```bash
papecode models anthropic
```

#### Флаги

| Флаг        | Описание                                                                          |
| ----------- | --------------------------------------------------------------------------------- |
| `--refresh` | Обновите кеш моделей на сайте models.dev.                                         |
| `--verbose` | Используйте более подробный вывод модели (включая метаданные, такие как затраты). |

Используйте флаг `--refresh` для обновления списка кэшированных моделей. Это полезно, когда к поставщику добавлены новые модели и вы хотите увидеть их в papecode.

```bash
papecode models --refresh
```

### run

Запустите papecode в неинтерактивном режиме, передав приглашение напрямую.

```bash
papecode run [message..]
```

Это полезно для создания сценариев, автоматизации или когда вам нужен быстрый ответ без запуска полного TUI. Например.

```bash "papecode run"
papecode run Explain the use of context in Go
```

Вы также можете подключиться к работающему экземпляру `papecode serve`, чтобы избежать холодной загрузки сервера MCP при каждом запуске:

```bash
# Start a headless server in one terminal
papecode serve

# In another terminal, run commands that attach to it
papecode run --attach http://localhost:4096 "Explain async/await in JavaScript"
```

#### Флаги

| Флаг         | Короткий | Описание                                                                         |
| ------------ | -------- | -------------------------------------------------------------------------------- |
| `--command`  |          | Команда для запуска, используйте сообщение для аргументов                        |
| `--continue` | `-c`     | Продолжить последний сеанс                                                       |
| `--session`  | `-s`     | Идентификатор сеанса для продолжения                                             |
| `--fork`     |          | Разветвить сеанс при продолжении (используйте с `--continue` или `--session`)    |
| `--share`    |          | Поделиться сеансом                                                               |
| `--model`    | `-m`     | Модель для использования в виде поставщика/модели.                               |
| `--agent`    |          | Агент для использования                                                          |
| `--file`     | `-f`     | Файл(ы) для прикрепления к сообщению                                             |
| `--format`   |          | Формат: по умолчанию (отформатированный) или json (необработанные события JSON). |
| `--title`    |          | Название сеанса (использует усеченное приглашение, если значение не указано)     |
| `--attach`   |          | Подключитесь к работающему серверу papecode (например, http://localhost:4096)    |
| `--port`     |          | Порт локального сервера (по умолчанию случайный порт)                            |

### serve

Запустите автономный сервер papecode для доступа к API. Полный HTTP-интерфейс можно найти в [server docs](/docs/server).

```bash
papecode serve
```

При этом запускается HTTP-сервер, который обеспечивает доступ API к функциям papecode без интерфейса TUI. Установите `PAPECODE_SERVER_PASSWORD`, чтобы включить базовую аутентификацию HTTP (имя пользователя по умолчанию — `papecode`).

#### Флаги

| Флаг         | Описание                                                      |
| ------------ | ------------------------------------------------------------- |
| `--port`     | Порт для прослушивания                                        |
| `--hostname` | Имя хоста для прослушивания                                   |
| `--mdns`     | Включить обнаружение mDNS                                     |
| `--cors`     | Дополнительные источники браузера, позволяющие разрешить CORS |

### stats

Покажите статистику использования токенов и затрат для ваших сеансов papecode.

```bash
papecode stats
```

#### Флаги

| Флаг        | Описание                                                                                                   |
| ----------- | ---------------------------------------------------------------------------------------------------------- |
| `--days`    | Показать статистику за последние N дней (все время)                                                        |
| `--tools`   | Количество инструментов для отображения (все)                                                              |
| `--models`  | Показать разбивку по использованию модели (по умолчанию скрыто). Передайте номер, чтобы показать верхнюю N |
| `--project` | Фильтровать по проекту (все проекты, пустая строка: текущий проект)                                        |

### export

Экспортируйте данные сеанса в формате JSON.

```bash
papecode export [sessionID]
```

Если вы не укажете идентификатор сеанса, вам будет предложено выбрать один из доступных сеансов.

### import

Импортируйте данные сеанса из файла JSON или URL-адреса общего ресурса papecode.

```bash
papecode import <file>
```

Вы можете импортировать из локального файла или URL-адреса общего ресурса papecode.

```bash
papecode import session.json
papecode import https://opncd.ai/s/abc123
```

#### Флаги

### acp

Запустите сервер ACP (агент-клиентский протокол).

```bash
papecode acp
```

Эта команда запускает сервер ACP, который обменивается данными через stdin/stdout с использованием nd-JSON.

#### Флаги

| Флаг         | Описание                    |
| ------------ | --------------------------- |
| `--cwd`      | Рабочий каталог             |
| `--port`     | Порт для прослушивания      |
| `--hostname` | Имя хоста для прослушивания |

---

### uninstall

Удалите papecode и удалите все связанные файлы.

```bash
papecode uninstall
```

#### Флаги

| Флаг            | Короткий | Описание                                   |
| --------------- | -------- | ------------------------------------------ |
| `--keep-config` | `-c`     | Сохраняйте файлы конфигурации              |
| `--keep-data`   | `-d`     | Храните данные сеанса и снимки             |
| `--dry-run`     |          | Покажите, что было бы удалено без удаления |
| `--force`       | `-f`     | Пропустить запросы подтверждения           |

---

### upgrade

Обновляет papecode до последней версии или определенной версии.

```bash
papecode upgrade [target]
```

Чтобы обновиться до последней версии.

```bash
papecode upgrade
```

Для обновления до определенной версии.

```bash
papecode upgrade v0.1.48
```

#### Флаги

| Флаг       | Короткий | Описание                                                  |
| ---------- | -------- | --------------------------------------------------------- |
| `--method` | `-m`     | Используемый метод установки: local, npm, pnpm, bun, brew |

| `PAPECODE_ENABLE_EXPERIMENTAL_MODELS` | логическое значение | Включить экспериментальные модели                                                |

| `PAPECODE_ENABLE_EXA`                 | логическое значение | Включить инструменты веб-поиска Exa                                              |

| `PAPECODE_SERVER_USERNAME`            | строка              | Переопределить имя пользователя базовой аутентификации (по умолчанию `papecode`) |
